## 📌 Sobre
Este projeto foi criado para servir como **laboratório de aprendizado** em Machine Learning.  
Aqui você encontrará:
- Notebooks com experimentos práticos
- Modelos clássicos (KNN, Decision Tree, Random Forest, etc.)
- Técnicas de feature engineering e pré-processamento
- Visualizações para interpretação dos resultados

Tecnologias principais:
- Python 3.x  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib / Seaborn
- Notebook
